# For My Paro ♡ — Rohit & Pratigya
A tiny mobile-friendly romantic website gift with a home surprise, personal love note, tap-the-heart game, love jar, promises and virtual hug.

## Files
- `index.html` — website
- `style.css` — responsive styling and animations
- `script.js` — game and interactions
- `assets/anime-couple.svg` — lightweight original vector couple illustration
- `assets/heart.svg` — favicon

## Run
Open `index.html` in a browser. No build step required. The tiny tune is synthesized by the browser and needs no audio file.

## GitHub Pages
1. Create a repository and upload all files, including the `assets` folder.
2. Open Settings → Pages.
3. Select Deploy from a branch, `main`, `/(root)`, then Save.
4. Wait for the published URL to appear.
